# Abstimmung Runde 2 (Detailfragen aus der Umsetzung)

Kontext: App „Elo-Duell“ (zwei Personen bewerten Listen per Duell auf dem Handy, tauschen Ranglisten per QR/Link, vergleichen). Jeweils ist die erste Option bereits umgesetzt; eine Änderung kostet wenig Aufwand.

- F4 Hinweistext, wenn nach bisherigen Duellen eine neue Option (0 Duelle) hinzukommt: A „Neue Option – noch ca. N Duelle bis zur ersten Rangliste“ (umgesetzt) · B Restduelle bis „stabil“ im Text nennen · C kein eigener Text, normaler Start-Hinweis.
- F5 Position neuer Listen in der Übersicht: A oben (umgesetzt) · B unten · C nach letzter Änderung sortiert.
- F6 Nach Import einer Sicherungsdatei: A Wechsel zur Übersicht mit Toast „Sicherung importiert“ (umgesetzt) · B in den Einstellungen bleiben.
- F7 Beim Import einer fremden Rangliste mit zusätzlichen Optionen: Checkbox „X neue Optionen übernehmen“: A standardmäßig aus (umgesetzt) · B standardmäßig an · C eigener Button, der sofort übernimmt.
- F8 Beim ersten Teilen fragt die App „Wie heißt du?“; wenn abgebrochen: A zurück zur Liste mit Hinweis (umgesetzt) · B ohne Namen teilen, Empfänger sieht „Unbekannt“ · C Pflichtfeld ohne Abbrechen.
- F9 Rangliste bei Optionen mit 0 Duellen: A 1.000 Punkte plus Badge „neu“, Platz „–“ (umgesetzt) · B „–“ statt Punkten · C Zeile ausblenden.
- F10 Neue Liste mit weniger als 2 Optionen speichern: A erlaubt, mit Warnung im Zähler und Leerzustand im Duell (umgesetzt) · B Speichern sperren.
